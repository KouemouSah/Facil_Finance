# Code de conduite

Ce projet adopte le [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : on s'adresse aux autres avec respect, on critique les idées et jamais les personnes, on accueille les contributeurs quels que soient leur langue (français, espagnol, portugais, anglais), leur pays et leur niveau.

**Spécifique à ce projet** : ne publiez jamais, dans un ticket, une discussion ou une demande de fusion, de données d'un client (balance, liasse, nom, identifiant fiscal, coordonnées), même pour illustrer un problème. Fabriquez un exemple synthétique.

Signalement d'un comportement inacceptable : **sah@emacsah.com**. Chaque signalement est traité avec confidentialité.
